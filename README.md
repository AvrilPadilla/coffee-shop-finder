# Coffee Shop Finder

A web app that helps you find coffee shops by wifi, outlets, noise level, and seating.

**Status:** In progress

## Planned features
- List of local coffee shops with details
- Filters for wifi, outlets, noise level, and seating
- Map view with a marker for each shop

## Built with
HTML, CSS, JavaScript, Leaflet (planned)

## How to run
Open `index.html` in your browser.
